# Gatito Petshop · Dashboard de vendas

Relatório em Power BI que acompanha faturamento e volume de vendas de um pet shop fictício. A análise combina indicadores gerais com recortes por período, bairro, gênero e produto.

![Captura do painel de vendas do Gatito Petshop](./Screenshot%202026-01-08%20201249.png)

## Perguntas que o relatório responde

| Pergunta | Visualização |
| --- | --- |
| Quanto foi vendido no período selecionado? | Indicadores de faturamento e quantidade de vendas. |
| Como o faturamento variou no tempo? | Série mensal de faturamento. |
| Quais bairros concentram as vendas? | Ranking de faturamento por bairro. |
| Como o faturamento se distribui por gênero? | Comparação de faturamento entre os grupos. |

Os filtros de data, marca e produto permitem comparar segmentos do mesmo conjunto de dados.

## Como abrir

A imagem acima mostra o painel sem precisar instalar ferramentas. Para usar os filtros, baixe [gatito.pbix](./gatito.pbix) e abra no Power BI Desktop. A base foi usada em um cenário fictício de estudo.
